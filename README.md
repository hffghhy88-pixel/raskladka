# Раскладка

Десктоп-приложение для кухни: считает **брутто / нетто / выход** блюда, вес каждого продукта и собирает из блюд **меню-раскладку** с закупкой.

Стек: **Electron + Vite + React + TypeScript** и эталонный движок на **Rust**.

Папка проекта: `Desktop/raskladka` — уже открыта в VS Code.

## Что умеет

1. Справочник продуктов: плотность, вес штуки, цена, КБЖУ, аллергены, профили потерь.
2. Конструктор блюда: закладка в любых единицах.
3. Расчёт веса: брутто, нетто после очистки, выход после варки/жарки.
4. Масштаб порций и обратный счёт «сколько порций из запаса».
5. Сборщик меню по дням и приёмам пищи.
6. Закупка: сумма сырья по меню минус склад.
7. Техкарта и калькуляционная карта, печать и Markdown.
8. Склад и минимальные остатки.
9. Отчёт КБЖУ на гостя и потери.
10. Rust-движок для независимой проверки тех же формул.

## Запуск

В терминале VS Code (PowerShell):

```powershell
cd $env:USERPROFILE\Desktop\raskladka
npm.cmd install
npm.cmd run rust:build
npm.cmd run dev
```

## Установщик и zip

```powershell
cd $env:USERPROFILE\Desktop\raskladka
npm.cmd run pack
```

Готовые файлы появятся в `release\`:

- `Раскладка-1.0.0-win-x64.exe` — установщик (можно выбрать папку, ярлыки на рабочий стол и в меню Пуск)
- `Раскладка-1.0.0-win-x64.zip` — портативная папка без установки

Копия тех же файлов также кладётся на рабочий стол.

Если политика PowerShell блокирует `npm`, всегда вызывайте `npm.cmd`.

Без Rust приложение тоже работает: интерфейс считает на TypeScript. Rust нужен как эталон (`Настройки → Проверить workspace в Rust`).

## Горячие места в коде

- `src/domain/calc.ts` — брутто / нетто / выход.
- `src/domain/menuCalc.ts` и `src/domain/shopping.ts` — меню и закупка.
- `rust/src/calc.rs` + `rust/src/engine.rs` — тот же расчёт на Rust.
- `src/data/` — демо-столовая: продукты, блюда, недельное меню.
